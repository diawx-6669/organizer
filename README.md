# Мой органайзер

Личный планировщик: уроки, домашка, события, цели и календарь — в одном месте.

## Структура проекта

```
index.html      — разметка страницы
css/styles.css  — все стили
js/app.js       — логика приложения (состояние, рендер, обработчики)
```

## Хранение данных

Все данные хранятся **локально в браузере** (`localStorage`) — ничего не уходит
на сервер и не требует аккаунта. Открывай сайт на одном и том же браузере
на своём Mac, и данные всегда будут на месте, даже после передеплоя сайта.

На всякий случай в интерфейсе есть кнопки:
- **скачать копию** — сохранить текущие данные в JSON-файл
- **загрузить копию** — вернуть данные из такого файла

## Расписание

Учебная неделя зашита в `js/app.js`:

- `SCHED_DATA` — недели A и Б, они чередуются сами от `SCHED_ANCHOR_MONDAY`
- `SCHED_ROOMS` — кабинеты
- `OFFICIAL_SUMMATIVES` — даты СОР из школьного расписания

Когда расписание суммативок меняется, правь `OFFICIAL_SUMMATIVES` и подними
`SUMM_SYNC_VERSION` на единицу. При следующем открытии сайта список сверится:
лишнее уберётся, недостающее добавится. Записи, где уже стоит балл, заметка
или галочка, не трогаются.

## Ветки

- `main` — стабильная версия
- `dev` — рабочая ветка для новых фич, потом мёржится в `main`

## Запуск

Просто открой `index.html` в браузере, или задеплой папку целиком
(например, на GitHub Pages / Vercel / Netlify) — она полностью статическая.
